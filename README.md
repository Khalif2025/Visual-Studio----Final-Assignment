# Favorite Song Webpage 🎵

This is a simple webpage created using **HTML, CSS, and JavaScript**.  
It features **Taylor Swift's song "Willow"** embedded from YouTube with a simple **bouncing animation**.

## Features:
✅ **YouTube Embedded Video** – Plays "Willow" by Taylor Swift  
✅ **Styled with CSS** – Custom background and text color  
✅ **JavaScript Animation** – A smooth bouncing effect on the video  

## How to Run:
1. Open `index.html` in a web browser.  
2. Enjoy the song and watch the animation in action!
